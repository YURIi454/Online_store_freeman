## Проект интернет-магазина на django
###### Учебный проект

### Реализовано в этом задании.
* Подключение СУБД PostgreSQL.
* В приложении __catalog__ созданы модели __Product__  и __Category__,
 сделаны базовые настройки.
* Сделаны миграции и сохранены в репозитории.
* Создан суперпользователь.
* Зарегистрированы модели __Product__ и __Category__ в "админке".
* Настроены отображения для моделей.
* Выполнены работы с инструментом Django shell (результаты в директории __screenshots__)
* Сформированы фикстуры моделей  __Product__ и __Category__ 
* Создана кастомная команда.
