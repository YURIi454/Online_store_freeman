## Учебный проект по Django

### Изменения в текущей версии

Установлен и настроен Redis как брокер для кеширования.

Настроено кеширование для страницы, подробной информации об одном продукте и одном блоге.

Добавлены сервисные функции, представления и шаблоны для работы
с товарами выбранной категории и блогами выбранной темы.

Реализовано низкоуровневое кеширование для списка продуктов и блогов.

#### Запуск сервера командой " __python manage.py runserver__"

После применения миграций необходимо запустить две команды,

1. python manage.py create_categories
2. python manage.py create_topics
   они автоматически заполнят таблицы Category и Topic нужными для корректной работы данными.
